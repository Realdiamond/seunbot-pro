# Project Summary
The USDT Trading Dashboard is an advanced web application tailored for cryptocurrency traders, focusing primarily on USDT trading pairs from Binance and insights from the Nigerian Stock Exchange (NGX). It provides real-time market data visualization and analytical tools through the Seun Bot, enhancing traders' decision-making capabilities. The platform includes a comprehensive S&P 500 stock dashboard, delivering live data from multiple financial data providers. The recent updates have integrated WebSocket technology for real-time price streaming, improving reliability and responsiveness without dependency on static data.

# Project Module Description
The dashboard includes several functional modules:
- **Seun Bot Analysis**: Advanced trading analysis with technical scoring and risk management.
- **Weekly Setups**: High-probability trading opportunities across USDT pairs and NGX stocks.
- **Trading Analysis**: In-depth analysis using various technical indicators and algorithms.
- **Data Visualization**: Interactive charts and real-time data for USDT pairs and NGX equities.
- **Cycle Analysis**: Evaluation of price cycles and trends for forecasting.
- **Market Overview**: Summary of market trends, showcasing top gainers and losers.
- **Performance Metrics**: Monitoring of trading performance and profitability.
- **Real-Time Performance Tracking**: Live price updates and performance against targets.
- **NGX Analysis**: Real-time analysis of Nigerian equities and ETFs.
- **AI Stock Analysis**: Enhanced AI-powered analysis using web search for detailed insights into NGX stocks and ETFs.
- **AI Insights**: Comprehensive AI-powered market analysis on the NGX Dashboard.
- **S&P 500 Dashboard**: Comprehensive dashboard for S&P 500 stocks with real-time data from multiple sources.
- **SeunBot Advanced Analysis**: Detailed technical analysis with multiple metrics and indicators for S&P 500 stocks.
- **Weekly Setups Panel**: Automated scanning for high-probability setups in S&P 500 stocks.
- **WebSocket Integration**: Real-time price streaming across all dashboard components with live status indicators.

# File Description Inventory

- **services/**: Fetches real-time price data and conducts trading analysis.

- **RealNGXDataService.js**: Service for fetching real-time NGX stock data using the Financial Data API.
- **AIStockAnalyzer.js**: AI analysis service that utilizes web search for stock data with enhanced features.
- **SP500DataService.js**: Service for fetching real-time S&P 500 stock data from multiple sources.
- **WebSocketService.js**: Core WebSocket service for real-time price streaming with automatic reconnection.
- **utils/**: Utility functions for data processing.
- **SP500Dashboard.jsx**: Displays the S&P 500 stock dashboard with advanced analysis and weekly setups.
- **SP500AdvancedAnalysis.jsx**: Component for advanced analysis of S&P 500 stocks.
- **SP500WeeklySetupsPanel.jsx**: Displays high-probability trading setups for S&P 500 stocks.
- **NGXDashboard.jsx**: Displays the NGX stock dashboard with live data.
- **NGXAdvancedAnalysis.jsx**: Component for advanced analysis of NGX stocks.
- **index.html**: Entry point HTML for the application.
- **package.json**: Defines project dependencies and scripts.
- **tailwind.config.js**: Configuration for customizing Tailwind CSS styles.
- **vite.config.js**: Configuration for Vite, the build tool.
- **postcss.config.js**: Configuration for PostCSS processing.
- **.env.example**: Template for API keys configuration for financial data providers.
- **API_SETUP_GUIDE.md**: Comprehensive guide for setting up financial data APIs.
- **AI_ANALYSIS_GUIDE.md**: Guide for setting up AI-powered stock analysis.

# Technology Stack
- **Frontend**: React, Tailwind CSS, shadcn-ui
- **Build Tool**: Vite
- **State Management**: React hooks
- **Data Visualization**: Recharts
- **Utilities**: Axios for HTTP requests
- **Real-Time Data**: WebSocket for price streaming

# Usage
1. Install dependencies:
   ```
   npm install
   ```
2. Build the application:
   ```
   npm run build
   ```
3. Run the application in development mode:
   ```
   npm run dev
   ```
4. Configure financial data APIs by setting up your API keys in the `.env` file based on the instructions in `API_SETUP_GUIDE.md`.
5. For AI stock analysis, ensure your OpenAI API key is configured in the `.env` file.
