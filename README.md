# SeunBot Pro

Advanced AI-powered trading analysis dashboard with modular components for NGX and Crypto markets.

## Getting Started

1. Clone the repository
2. Run `npm install`
3. Set your environment variables (see `.env.example`)
4. Run `npm run dev`

## Deployment

For production deployments (like Vercel or Netlify), be sure to configure your environment variables in the deployment dashboard rather than committing `.env` files.
